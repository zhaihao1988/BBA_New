# 年初预期与期末预期差异说明

## 问题

为什么 `Pvfl_If_Bop_Cfa_Rep_Wlk_Cla_Amt`（年初预期）和 `Pvfl_If_Eop_Cfa_Rep_Wlk_Cla_Amt`（期末预期）的值不一样？

## 答案：这是正常的！

这两个值**应该不一样**，因为：

### 1. 使用不同的精算假设

- **年初预期**（`Pvfl_If_Bop_Cfa_Rep_Wlk_Cla_Amt`）：
  - 使用**上年末精算假设**（`assump_prev_ye`）
  - 基于上年12月31日的精算假设生成现金流
  
- **期末预期**（`Pvfl_If_Eop_Cfa_Rep_Wlk_Cla_Amt`）：
  - 使用**当前评估月精算假设**（`assump_val`）
  - 基于当前评估月（如2024年12月）的精算假设生成现金流

### 2. 计算逻辑相同，但输入不同

两个字段的计算逻辑完全相同：
- 都是计算**评估月之后的赔付现金流**
- 都折现至**评估期末**（`val_month_end`）
- 都使用**加权初始确认利率**（Wlk）

**唯一的区别**是使用的精算假设不同。

### 3. 差异的含义

从日志中看到：
- 年初预期 = 3,687.27
- 期末预期 = 2,357.48
- 差异 = -1,329.79

这个差异表示：
- **精算假设的变化**导致预期赔付现值减少了 1,329.79
- 可能的原因：
  - 赔付率（loss_ratio）降低
  - 间接理赔费用率（indirect_claims_expense_ratio）降低
  - 其他精算假设参数的变化

### 4. 符合IFRS 17要求

这正是IFRS 17的要求：
- **年初预期**应该基于**年初时的精算假设**（上年末假设）
- **期末预期**应该基于**期末时的精算假设**（当前评估月假设）
- **差异**反映了精算假设变化的影响，这是**履约现金流变化**的一部分

## 什么时候两个值会一样？

只有在以下情况下，两个值才会一样：
1. **精算假设没有变化**：上年末假设 = 当前评估月假设
2. **没有时间推移**：年初 = 期末（这种情况不存在）

## 验证修复是否生效

要验证修复是否生效，可以检查：

1. **年初预期是否使用了上年末假设**
   - 查看 `pv_calculator.py` 第517-520行：是否保存了 `cf_prev_ye` 到 `bop_cf_by_year`
   - 查看第690-698行：是否使用了 `bop_cf_by_year` 或 `cf_prev_ye`

2. **期末预期是否使用了当前评估月假设**
   - 查看第522-524行：`cf_val` 是否基于 `assump_val` 生成

3. **精算假设是否真的不同**
   - 检查上年末假设（`assump_prev_ye`）和当前评估月假设（`assump_val`）的值
   - 如果假设相同，但值不同，可能是其他原因（如时间推移、实际赔付等）

## 总结

**这两个值不一样是正常的，符合IFRS 17的要求。** 差异反映了精算假设变化对预期现金流的影响。
