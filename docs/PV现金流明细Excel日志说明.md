# PV现金流明细Excel日志说明

## 概述

PV现金流明细Excel日志是一个详细的Excel文件，用于记录每个评估期的现金流投射、PV原材料值计算过程和利率计算明细。每年一个sheet，方便查看和对比。

## 文件格式

- **文件格式**: Excel (.xlsx)
- **文件命名**: `pv_cashflow_detail_{保单号}_{时间戳}.xlsx`
- **保存位置**: `logs/` 目录

## Sheet结构

每个年度一个sheet，sheet名称为：`{年份}年`（如：`2021年`、`2022年`）

## 每个Sheet包含的内容

### 1. 保单信息
- 保单号
- 签单日期
- 起保日期
- 终保日期
- 保修结束日期
- 签单保费

### 2. 精算假设
- 赔付率
- 间接理赔费用率
- 维持费用率
- 非金融风险调整率
- 获取费用率

### 3. 利率曲线信息

#### 3.1 锁定利率曲线（基于签单日期）
- 期限（月）
- 远期月利率
- 折现因子（累计）
- 说明

#### 3.2 期末利率曲线（基于评估日期）
- 期限（月）
- 远期月利率
- 折现因子（累计）
- 说明

**注意**: 只显示前100个期限，避免文件过大

### 4. 月度现金流投射明细

包含从签单日至终保日的完整月度现金流：

| 年月 | 日期 | 保费流入 | IACF流出 | 赔付流出 | 维持费用流出 | 风险期 | 说明 |
|------|------|---------|---------|---------|------------|--------|------|
| 202105 | 2021-05-01 | 124,500.00 | 18,910.11 | 0.00 | 0.00 | ❌ | 保修期内 |
| ... | ... | ... | ... | ... | ... | ... | ... |
| 202807 | 2028-07-01 | 0.00 | 0.00 | 1,234.56 | 123.45 | ✅ | 风险期内 |

**说明**:
- **风险期标识**: ✅ 表示在风险期内，❌ 表示在保修期内
- **风险期**: 从保修结束日期开始至终保日期
- **现金流计算**:
  - 保费：仅在签单月收取
  - IACF：仅在签单月支付
  - 赔付：风险期内每月 = (签单保费 / 风险期月数) × 赔付率 × (1 + 间接理赔费用率)
  - 维持费用：风险期内每月 = (签单保费 / 风险期月数) × 维持费用率

## 使用说明

1. **打开Excel文件**: 使用Excel或WPS等软件打开
2. **查看不同年度**: 点击底部的sheet标签切换不同年度
3. **筛选和排序**: 可以对表格数据进行筛选和排序
4. **导出数据**: 可以复制表格数据到其他工具进行分析

## 注意事项

1. **文件大小**: 如果现金流数据量很大，文件可能会比较大
2. **利率曲线**: 只显示前100个期限，完整数据请查看数据库
3. **折现因子计算**: 只显示前10个示例，完整计算过程需要查看源代码
4. **数据来源**: 
   - 现金流：基于精算假设和保单信息实时计算
   - PV值：从PV原材料数据文件读取
   - 利率曲线：从数据库读取
