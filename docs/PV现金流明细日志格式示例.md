### 5. 利率计算明细

#### 5.1 折现因子计算示例（以2028-07-01的现金流为例）

**现金流信息**:
- **日期**: 2028-07-01
- **金额**: 1,234.56（赔付）
- **评估日期**: 2021-12-31
- **基准日期**: 2021-05-01（锁定利率曲线基准）

**计算步骤**:

1. **计算距离基准月数**:
   ```
   从 2021-05-01 到 2028-07-01
   = (2028 - 2021) × 12 + (7 - 5)
   = 7 × 12 + 2
   = 86 个月
   ```

2. **计算折现因子**:
   ```
   DF = 1 / [(1+r₁)×(1+r₂)×...×(1+r₈₆)]
   
   其中：
   r₁ = 0.001478 (第1个月远期利率)
   r₂ = 0.001480 (第2个月远期利率)
   ...
   r₈₆ = 0.001520 (第86个月远期利率，从曲线获取或外推)
   
   DF = 1 / [1.001478 × 1.001480 × ... × 1.001520]
     = 1 / 1.136234
     = 0.880123
   ```

3. **计算现值**:
   ```
   PV = CF × DF
     = 1,234.56 × 0.880123
     = 1,086.78
   ```

#### 5.2 利率曲线外推规则

当现金流日期超出利率曲线最大期限时，使用以下规则：

- **外推方法**: 使用曲线最后一个有效利率
- **示例**: 如果曲线最大期限为720个月，而现金流在第800个月，则使用 r₇₂₀ 作为 r₈₀₀
