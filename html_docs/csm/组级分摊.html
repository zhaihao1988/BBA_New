IFRS 17 分摊策略看板

合同组 (Group) 与 保单 (Policy) 之间的数据流向图解

无需分摊 (Type A)
必须分摊 (Type B)

Type A: 自下而上 (Bottom-Up)

无需分摊

天然属于保单层级的数据，系统先算保单，再汇总至合同组。

典型字段：BEL现值、履约现金流变动、保费收入

Type B: 自上而下 (Top-Down)

必须分摊

天然属于合同组属性（CSM/LC），必须按规则“刷回”保单才能做明细分析。

典型字段：CSM/LC余额、CSM计息、解锁与吸收、摊销

字段分摊策略矩阵

字段名称 类型 策略判定 执行逻辑
IF_年初CSM余额 Type B 需分摊 基于上期期末分摊结果结转。
IF_年初LC (及明细) Type B 需分摊 按保单的 BEL 比例或亏损贡献度分摊。
当年新增合同CSM Type B 需分摊 即使某单盈利，若组亏损，该单CSM需抵消为0（即分摊结果为0）。
NB_初始确认_现金流/RA Type A 无需分摊 定价引擎直接产出，直接汇总。
字段名称 类型 策略判定 执行逻辑
IF_待分摊IFIE_计息 (BEL/RA) Type A 无需分摊 保单 BEL * 锁定利率，天然可算。
CSM计息 / 期初有效CSM计息 Type B 需分摊 按保单期初 CSM 余额占比分摊。
IF_LC分摊IFIE (亏损利息) Type B 需分摊 这是 LC 变动的一部分，按保单 LC 余额占比分摊。

注意：这是最复杂的逻辑。保单自身的现金流变动（Type A）可能会触发合同组层级的 CSM/LC 转换，该转换结果（Type B）必须分摊回来，可能涉及“交叉补贴”。

字段名称 类型 策略判定 执行逻辑
履约现金流变动 (Delta FCF) Type A 无需分摊 例如实际理赔与预期的差额，属于保单自身属性。
被CSM吸收的变化 Type B 需分摊 如果组CSM足够，吸收该变动。需分摊以更新保单CSM。
被LC吸收的变化 Type B 需分摊 如果组亏损，变动计入P&L并调整LC。需分摊以更新保单LC。
字段名称 类型 策略判定 执行逻辑
摊销的CSM (保险收入) Type B 需分摊 按保单贡献的保障单元 (Coverage Units) 分摊。
期末CSM/LC余额 Type B 需分摊 公式：保单期初 + 分摊的新增 + 分摊的利息 + 分摊的吸收 - 分摊的摊销。
