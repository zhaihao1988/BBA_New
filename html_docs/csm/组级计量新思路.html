场景1: 亏转亏 (Loss to Loss)

期初状态: LC = -150, CSM = 0
本期变化: Delta = +10
期末试算: Net = -141.80 (仍亏损)
判定结果: 走LC逻辑
保单明细:
IF（有效合同-期初）: Pol_A: LC=-100, Pol_B: LC=-50 (合计LC=-150)
NB（新增合同-初始确认）: Pol_C: CSM=+20 (盈利), Pol_D: LC=-20 (亏损)
合计: LC=-170, CSM=+20, 净额=-150

1 步骤1: CSM计息

IF_年初CSM余额

IF_年初CSM余额 = 年初CSM(直接取数) = 0.00

IF两个保单都是亏损，无CSM

IF_CSM计息

IF_CSM计息 = IF_年初余额 × ((1+r₁)×(1+r₂)×...×(1+r₁₂) - 1)

期初CSM = 0，计息 = 0

= 0.00

NB_新增CSM

NB_新增CSM = SUM(当年各月新增CSM/LC中>=0的值)

Pol_C: CSM=+20 (盈利合同)

= 20.00

NB_CSM计息

NB_CSM计息 = SUM(各月新增CSM × ((1+r)^初始确认时点 - 1))

假设Pol_C在6月签单，计息因子=0.03

= 20 × 0.03 = 0.60

IF_计息后CSM = 0 + 0 = 0.00

NB_计息后CSM = 20 + 0.60 = 20.60

2 步骤2: LC分摊IFIE

IF_年初LC

IF_年初LC = 年初LC(直接取数) = -150.00

Pol_A: LC=-100, Pol_B: LC=-50, 合计=-150

IF_LC IFIE分摊比例

IF(IF_年初LC < 0, IF_年初LC / (PV_赔付 + PV_费用 + PV_RA), 0)

假设分母 = 750

= -150 / 750 = -0.20 (注意：LC为负，比例也为负)

NB_新增LC

NB_新增LC = SUM(当年各月新增CSM/LC中<0的值)

Pol_D: LC=-20 (亏损合同)

= -20.00

NB_LC IFIE分摊比例

IF(NB_新增LC < 0, NB_新增LC / (PV_赔付 + PV_费用 + PV_RA), 0)

假设分母 = 100

= -20 / 100 = -0.20

IF_待分摊IFIE_计息_赔付与费用

【有效合同-年初预期-预期未来-预期赔付现金流-期末现值(加权初始确认利率)】+
【有效合同-年初预期-预期未来-预期维持费用现金流-期末现值(加权初始确认利率)】+
【有效合同-年初预期-预期当年-预期赔付现金流-期末现值(加权初始确认利率)】+
【有效合同-年初预期-预期当年-预期维持费用现金流-期末现值(加权初始确认利率)】-
【有效合同-年初预期-预期未来-预期赔付现金流-年初现值(上年)加权初始确认利率】-
【有效合同-年初预期-预期未来-预期维持费用现金流-年初现值(上年)加权初始确认利率】

假设计算结果 = 5.00

IF_LC分摊IFIE_赔付与费用

IF_LC分摊IFIE_赔付与费用 = (IF_待分摊IFIE_计息_赔付与费用 + IF_待分摊IFIE_利率变化的影响_赔付与费用) × IF_LC IFIE分摊比例

假设待分摊IFIE = 5.00, 利率变化影响 = 2.00

= (5.00 + 2.00) × (-0.20) = -1.40

注意：LC为负，分摊IFIE也为负（与LC方向相同）

NB_LC分摊IFIE_赔付与费用

NB_LC分摊IFIE_赔付与费用 = (NB_待分摊IFIE_计息_赔付与费用 + NB_待分摊IFIE_利率变化的影响_赔付与费用) × NB_LC IFIE分摊比例

假设待分摊IFIE = 1.00, 利率变化影响 = 0.50

= (1.00 + 0.50) × (-0.20) = -0.30

IF_LC分摊IFIE = -1.40 + (-0.60) = -2.00

IF_分摊后IFIE后LC = -150 + (-2.00) = -152.00

NB_LC分摊IFIE = -0.30 + (-0.10) = -0.40

NB_分摊后IFIE后LC = -20 + (-0.40) = -20.40

Pol_A (IF):

预期现金流变化 = +6.00, 非金融风险调整变化 = 0, 其他变化 = 0

Delta_A = 6.00 + 0 + 0 = +6.00

Pol_B (IF):

预期现金流变化 = +4.00, 非金融风险调整变化 = 0, 其他变化 = 0

Delta_B = 4.00 + 0 + 0 = +4.00

Pol_C (NB):

预期现金流变化 = 0, 非金融风险调整变化 = 0, 其他变化 = 0

Delta_C = 0 + 0 + 0 = 0.00

Pol_D (NB):

预期现金流变化 = 0, 非金融风险调整变化 = 0, 其他变化 = 0

Delta_D = 0 + 0 + 0 = 0.00

合计:

Delta_合计 = 6.00 + 4.00 + 0 + 0 = +10.00

4 步骤4: 合同组CSM/LC判断

Net Trial = IF_计息后CSM + NB_计息后CSM + IF_分摊后IFIE后LC + NB_分摊后IFIE后LC + Delta_合计

= 0 + 20.60 + (-152.00) + (-20.40) + 10.00 = -141.80

(IF_计息后CSM=0, NB_计息后CSM=20.60, IF_分摊后IFIE后LC=-152.00, NB_分摊后IFIE后LC=-20.40, Delta_合计=+10.00)

IF(Net Trial >= 0, 合同组CSM = Net Trial, 合同组LC = Net Trial)

合同组CSM = 0

合同组LC = -141.80

5 步骤5: CSM计量

被CSM吸收的变化

IF(OR(AND(合同组CSM > 0, SUM(合同组CSM, 被CSM/LC吸收的变化合计) >= 0),
AND(合同组CSM = 0, SUM(合同组LC, 分摊的LC, 被CSM/LC吸收的变化合计) >= 0)),

-SUM(年初CSM余额, 当年新增CSM, CSM计息))

条件1: 合同组CSM = 0, 不满足

条件2: 合同组CSM = 0, SUM(合同组LC, 分摊的LC, Delta) = -141.80 + (-5) + 10 = -136.80 < 0, 不满足

走ELSE分支: -SUM(0, 20, 0.60) = -20.60

(年初CSM余额=0, 当年新增CSM=20, CSM计息=0.60)

注意：这20.60的CSM被LC吸收，Pol_C的"被CSM吸收的变化"为-20.60（减少CSM），同时这20.60会按分摊后LC比例分摊给A、B、D三个亏损保单（增加LC吸收）

被CSM吸收的现金流变化

被CSM吸收的现金流变化 = 预期现金流变化合计 - 被LC吸收的变化_预期现金流

假设预期现金流变化合计 = 10, 被LC吸收的变化_预期现金流 = 30.60

= 10 - 30.60 = -20.60

注意：这-20.60对应Pol_C的"被CSM吸收的现金流变化"为-20.60（减少CSM），同时这20.60会按分摊后LC比例分摊给A、B、D（增加LC吸收）

被CSM吸收的非金融风险调整变化

被CSM吸收的非金融风险调整变化 = 非金融风险调整变化 - 被LC吸收的变化_非金融风险调整

假设非金融风险调整变化 = 0, 被LC吸收的变化_非金融风险调整 = 0

= 0 - 0 = 0.00

6 步骤6: LC计量

被LC吸收的变化_合计

IF(OR(AND(合同组LC < 0, SUM(合同组LC, 分摊的LC, 被CSM/LC吸收的变化合计) < 0),
AND(合同组LC = 0, SUM(合同组CSM, 被CSM/LC吸收的变化合计) < 0)),
SUM(被CSM/LC吸收的变化合计, 年初CSM余额, 当年新增CSM, CSM计息),
-SUM(年初LC余额_合计, 当年新增LC_合计, LC分摊IFIE_合计, 分摊的LC_合计))

条件1: 合同组LC = -141.80 < 0, SUM(-141.80, -5, 10) = -136.80 < 0, 满足

走THEN分支: SUM(10, 0, 20, 0.60) = 30.60

(被CSM/LC吸收的变化合计 = Delta_合计 = 10.00, 年初CSM余额 = 0, 当年新增CSM = 20, CSM计息 = 0.60)

注意：虽然最终走LC逻辑，但NB的CSM(+20.60)也要被LC吸收

实际被LC吸收的变化_合计 = 10.00 + 20.60 = 30.60

其中Delta_合计(10.00)和NB的CSM(20.60)都按分摊后LC比例分摊给A、B、D三个亏损保单

被LC吸收的变化_预期现金流

被LC吸收的变化_预期现金流 = 被LC吸收的变化合计 × (预期现金流变化合计 / 被CSM/LC吸收的变化合计)

= 30.60 × (10 / 10) = 30.60

注意：这30.60包括Delta的现金流变化(10.00)和NB的CSM(20.60)，都按分摊后LC比例分摊给A、B、D

被LC吸收的变化_非金融风险调整

被LC吸收的变化_非金融风险调整 = 被LC吸收的变化合计 - 被LC吸收的变化_预期现金流

= 30.60 - 30.60 = 0.00
